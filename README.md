# Check Even or Odd

Bu proje, bir sayının **tek mi** yoksa **çift mi** olduğunu kontrol eder.

## Kullanım Talimatları

1. Java'yı bilgisayarınızda kurun.
2. `CheckEvenOdd.java` dosyasını indirip çalıştırın.
3. Sayı girdiğinizde, program size bu sayının tek mi çift mi olduğunu söyleyecektir.

## Çalıştırma:
Java'yı yükledikten sonra terminal veya komut istemcisinde şu komutu çalıştırarak programı çalıştırabilirsiniz:

```bash
javac CheckEvenOdd.java
java CheckEvenOdd
